# AI use disclosure

## Summary

**100% of the Lunex project code was AI-generated/authored using OpenAI ChatGPT under human direction.**

The team used AI to generate the code. Humans were responsible for setting the requirements, directing and refining the implementation, reviewing the generated code, checking the authenticity and provenance of data/source claims, reviewing scientific logic and assumptions, and testing/validating the resulting application.

This is not a human-written-code or 80/20 authorship claim. Code authorship is disclosed as 100% AI-generated.

## Human oversight

Human contributions included:
- Defining the challenge interpretation, intended user workflow, and product requirements.
- Directing AI coding iterations and choosing which implementation changes to keep.
- Reviewing generated implementation and integration behavior.
- Checking NASA/JPL source references and reviewing how scientific data is interpreted.
- Testing the application and reviewing test/build/lint outcomes.
- Deciding how to represent partial data, unknown terrain coverage, and model limitations.

Human review does not change the stated AI authorship of the code.

## Images and video

- AI-generated project images: **No**.
- AI-generated project video: **No**.

Where external imagery, models, or raster data are used, their source and license/terms must be documented independently. AI-generated code does not imply AI-generated NASA observations or NASA data.
